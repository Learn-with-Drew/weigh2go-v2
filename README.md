# weigh2go-v2

## Intro

This project is a revamp or rebuild of an old project I worked on, Weigh to Go, which was an android app, but I'm revamping it as a web application. I'm calling it, Weigh 2 Go. The core of this web application is to help people track their weight and visually see their food/calorie intake. In today's world, where eating processed and fast foods is easily obtainable, this will help showcase how bad it can be for their health. Honestly, creating this app in hopes of creating a healthier lifestyle.

Why a rebuild? This will help me learn a lot of the new and up to date web, front-end, and back-end technology.
